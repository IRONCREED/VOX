# Акт о системе диаграмм IRONCREED

Редакция: `1.0.0`.

Идентификатор: `icw-act-diagram-system-001`.

Дата принятия: 2026-09-01.

Классы Законодательства: Z02, Z07, Z08, Z09, Z11, Z12.

Конституционное основание: I.2–I.3, II.2, II.4, VI.1, VI.4 принятой
«Конституции кода», P04, P06, P12, P15–P17 Учредительного профиля и акты
`icw-act-semantic-core-001`, `icw-act-site-experience-001`,
`icw-act-content-lifecycle-001`.

## ICW-DG01. Единственный источник

Диаграмма является проекцией канонических сущностей и отношений
`semantic-core`, а не отдельным вручную поддерживаемым документом. Её договор
имеет последовательность `Entity → Relation → Projection → Layout → Renderer`.
Форматы React Flow, ELK и экспортные изображения источниками данных не являются.

## ICW-DG02. Декларация и идентичность

Каждое графическое задание сохраняет stable ID `asset.*`. Реализованная
диаграмма получает `assetType: diagram`, канонический `source`, projection,
renderer, preset, представления, узлы и отношения. Одна сущность сохраняет один
ID во всех проекциях. Копирование сущности для отдельного изображения запрещено.

Координаты не принадлежат канонической сущности и вычисляются ELK. Допустимы
только минимальные `layoutOverrides`, явно принадлежащие конкретной проекции.

## ICW-DG03. Типы и специализированные представления

Поддерживаются `flow`, `lifecycle`, `gate`, `lineage`, `topology`, `navigator`,
`warden`, `matrix`, `comparison`, `hero`. Графовые представления использует
React Flow; `matrix` вправе использовать CSS Grid/SVG. Другой renderer не
создаёт новый источник данных.

## ICW-DG04. Интерактивность и публикация

Interactive-режим разрешает pan, zoom, focus и раскрытие трассы, но не публичное
редактирование канона. Publication-режим детерминирован, не содержит edit/drag
controls и обязан иметь локализованные `alt`, `title`, caption и provenance.
Производные SVG/WebP/PNG пересобираются Playwright и не принимаются как источник.

## ICW-DG05. Серии

Связанные материалы по возможности используют один системный asset и разные
проекции, режимы и активные состояния. Общие узлы и отношения между частями не
копируются. Локальные overrides не меняют идентичность общей системы.

## ICW-DG06. Визуальный язык

Синий обозначает активный маршрут, золотой — подтверждённое или пройденное,
красный — конфликт или отклонение, светлая граница — человеческое решение,
графитовый — фон и вторичные структуры. Форма линии дублирует семантику связи;
значение не зависит только от цвета. Технические значения используют monospace.

## ICW-DG07. Выпускной запрет

WARDEN блокирует выпуск при неразрешимом source/entity/relation, повторённом
локальном узле, неизвестном типе, renderer/projection conflict, координатах в
каноническом layout, отсутствующей локали или публикационной доступности. Пока
индивидуальные параметры не утверждены, редакционные задания остаются
`editorial-request`; инфраструктурный выпуск не создаёт фиктивных диаграмм.
